# QueenCosy - BOM & Cost Calculator (Standalone Web + Shared Supabase DB) 🛒💰

> **ระบบคำนวณสูตร BOM วัตถุดิบ, งบประมาณสั่งซื้อ PO และต้นทุนต่อชิ้น พร้อมฐานข้อมูลกลาง Supabase สำหรับทีมงาน**
> 
> **CRITICAL ARCHITECTURE NOTE:** ระบบนี้ทำงานแยกอิสระจากระบบไลน์ผลิต (	raceability-web) อย่างสิ้นเชิง โดยใช้ Namespace ตารางแยกเฉพาะ om_calc_* ไม่กระทบต่อ production_batches หรือการออก QR Code หน้างานโรงงาน

---

## 🎯 วัตถุประสงค์ (Purpose)
- ให้ฝ่ายจัดซื้อ (Procurement) และแอดมิน (Admin) คีย์จำนวนสินค้าหรืออัปโหลดออเดอร์เพื่อดูปริมาณความต้องการวัตถุดิบ (ผ้า, ไม้, ฟองน้ำ, บรรจุภัณฑ์ ฯลฯ)
- **แชร์ฐานข้อมูลกลาง (Central Shared DB):** พนักงานทุกคนใช้ราคาต้นทุนวัตถุดิบเดียวกัน สต็อกปัจจุบันเดียวกัน และเห็นแผนสั่งซื้อร่วมกันแบบ Real-time
- **ระบบบันทึกแผนคำนวณ (Saved Plans):** สามารถตั้งชื่อและบันทึกแผนคำนวณสั่งซื้อเก็บไว้ เพื่อให้เพื่อนร่วมงานเปิดดู โหลดกลับมาคำนวณใหม่ หรือตรวจสอบประวัติได้
- **ระบบทำงานได้ 100% ทั้งแบบออนไลน์ (Supabase) และออฟไลน์ (LocalStorage):** แม้ไม่มีเน็ตหรือยังไม่รัน Migration หน้าเว็บก็ทำงานได้ปกติไม่ค้าง
- ส่งออกรายงาน Excel และพิมพ์ใบสรุปงบประมาณสั่งซื้อ PO ได้ทันที

## 🌟 ฟังก์ชันการทำงานหลัก (Key Features)

1. **📋 รายการสินค้าที่ต้องการคำนวณสั่งซื้อ (Product Plan):**
   - รองรับการนำเข้าไฟล์ Excel ออเดอร์ (Shopee, TikTok หรือ Template มาตรฐาน)
   - หยอดจำนวนชิ้นได้อิสระ คำนวณต้นทุนต่อตัวและต้นทุนรวมให้อัตโนมัติ
   - ปุ่ม **💾 บันทึกแผนคำนวณ** บันทึกลงฐานข้อมูลกลาง Supabase
   - ปุ่ม **📂 แผนสั่งซื้อที่บันทึกไว้** เปิดดูและโหลดแผนที่เพื่อนร่วมงานบันทึกไว้
   - ปุ่ม **📥 ส่งออกใบสั่งซื้อ (Excel)** และ **🖨️ พิมพ์สรุป**

2. **🪵 สรุปความต้องการวัตถุดิบ (BOM Summary):**
   - คำนวณความต้องการใช้วัตถุดิบสุทธิครบ 43 ชนิด (โครงสร้างไม้, ฟองน้ำ, หนังและผ้า, บรรจุภัณฑ์)
   - ส่งออกใบเบิกวัตถุดิบฝ่ายผลิต (.xlsx)

3. **📊 ตรวจสต็อกและสั่งซื้อ (Stock Check & PO):**
   - คีย์สต็อกปัจจุบัน เพื่อคำนวณยอดที่ขาดและงบสั่งซื้อ PO แบบ Real-time
   - ข้อมูลสต็อกจะซิงค์ขึ้นฐานข้อมูลกลาง Supabase เพื่อให้ทุกคนเห็นสต็อกตรงกัน

4. **💰 จัดการราคาต้นทุนวัสดุ (Material Price Master):**
   - ปรับแก้ไขราคาต่อหน่วยของวัตถุดิบทั้ง 43 ชนิด
   - บันทึกและซิงค์ขึ้น Supabase Real-time พร้อมออฟไลน์สำรองในเครื่อง

5. **🔍 คลังสูตร Master BOM (Catalog & Recipe Editor):**
   - คลังสูตรเฟอร์นิเจอร์ 423 รุ่นมาตรฐานโรงงาน
   - แก้ไขสูตรหรือเพิ่มรุ่นใหม่ สูตรที่ปรับปรุงจะซิงค์ไปยังผู้ใช้อื่นทันที

## 🗄️ โครงสร้างฐานข้อมูลกลาง Supabase (Isolated Tables)

ฐานข้อมูลของ BOM Calculator จะใช้คำนำหน้า om_calc_* ทั้งหมด เพื่อไม่ให้ปะปนกับฐานข้อมูลระบบโรงงาน:

1. public.bom_calc_material_prices:
   - เก็บราคาต้นทุนต่อหน่วย, หมวดหมู่, หน่วยนับ, สต็อกปัจจุบัน และ % เผื่อสูญเสีย
   - พรีโหลดราคามาตรฐานครบ 43 รายการ
2. public.bom_calc_saved_plans:
   - เก็บแผนคำนวณและสั่งซื้อที่บันทึกไว้ (Plan ID, ชื่อแผน, ยอดชิ้น, งบ PO, ข้อมูล JSON ออเดอร์)
3. public.bom_calc_custom_recipes:
   - เก็บสูตร BOM ของรุ่นที่มีการปรับปรุงหรือเพิ่มใหม่

## 🚀 วิธีตั้งค่าตารางบน Supabase (SQL Migration)

ให้ผู้ดูแลระบบคัดลอกคำสั่งในไฟล์ MIGRATION_BOM_CALCULATOR_SHARED_DB.sql ไปรันใน **Supabase Dashboard -> SQL Editor**:
1. เปิดหน้า Supabase Project -> เลือกเมนู **SQL Editor**
2. เปิดไฟล์ MIGRATION_BOM_CALCULATOR_SHARED_DB.sql แล้วกด **Run**
3. เมื่อรันเสร็จเรียบร้อย หน้าเว็บ https://bom-calculator-web.vercel.app/ จะแสดงสถานะ:
   🟢 คลาวด์ออนไลน์ (ฐานข้อมูลกลาง) ทันที
